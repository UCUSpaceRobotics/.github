# UCU Space Robotics

We are a student robotics team from Ukrainian Catholic University building 
the **Indomitus** mars rover to compete at the 
[European Rover Challenge](https://roverchallenge.eu).

## Repositories
| Repo | Description |
|------|-------------|
| `indomitus-rover-core` | ROS2 software stack (simulation, navigation, control) |
| `indomitus-arm-ros2` | ROS2 controller for robotic arm |
| `indomitus-drone-ros2` | ROS2 controller for drone |
| `indomitus-rover-hw` | Hardware drivers and embedded firmware |
